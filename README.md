# Учебный проект для освоения Java.

# Проект представляет собой шахматный движок с CLI управлением

## Реализовано:
- отрисовка доски и инструкции по пользованию в консоли
- перемещение фигур
- взятие фигур
- определение шаха
- определение мата
- проверка корректности ходов

---
## Jar файл для запуска можете найти в разделе [релизов](https://github.com/Nitor112221/chess/releases)
## Для запуска используйте команду в директории с jar файлом  
```bash
java -jar build.jar
```
